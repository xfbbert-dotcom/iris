独立审查将旧同群回复过渡期体验列为 P2 后续，不为恢复旧回答而放开不明来源。

在9月9日回答时未明确相对日期的参照日；另一用例正确给出9月7/8日绝对日期。

但不算日期表达完全通过。后续应优先使用绝对日期或明确“原帖所称今天/昨天”，
